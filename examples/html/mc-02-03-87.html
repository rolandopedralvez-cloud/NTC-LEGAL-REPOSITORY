Memorandum Circular No. 02-03-87 — Implementation of the Revised Amateur Regulations

Status
Active
Issued
February 3, 1987
Implements
Ministry Circular 87-174 (dated Feb 3, 1987)
Issued By
Commissioner Rosauro V. Sibal

Issued to effectively implement the revised Amateur Radio Service regulations set out in MC 87-174.

Section II.1 — Accreditation of Amateur Organizations

Requires SEC registration/Articles of Incorporation, member list, and certified officer list. Accredited organizations sign an MOA with NTC for managing member frequency use and interference prevention.

Section II.2 — Call Signs

Call sign prefixes: DU (Classes A–C), DY (Class D), DX/DZ (club/field/special-event stations), followed by district figure and up to 3-letter suffix. Class A operators may optionally use prefix 4D–4F. Call signs must be transmitted at start/end of each transmission. Posting requirements: 10cm-high characters at fixed station entrances, 5.08cm on mobile vehicle/vessel windshields, 0.635cm on portable equipment.

Section II.3 — Field Trips and DX-Expeditions

Requires a written request to NTC for a temporary permit to operate during a special field trip or DX-expedition.

Section II.4 — Amateur Examination

Required elements by class: Class A (Elements I, VIII, IX, X); Class B (Elements I–VII); Class C (Elements I–IV); Class D (Elements II–IV). Upgrade paths allow skipping previously-passed elements (except Element I). Class B applicants for Class A must hold a valid Class B license for 1+ year. Extensive syllabi cover Radio Rules (Element II), Electrical/Electronics Principles (Element III), Amateur Radio Practice (Element IV), Signals and Emissions (Element V), Circuit Components (Element VI), Operating Procedures (Element VII), Practical Circuits (Element VIII), Antennas and Feedlines (Element IX), and Radio Wave Propagation (Element X).

Sections II.5–7 — License Scope, Form, Requirements

Amateurs operate only per their license class, sub-allocated bands, and authorized emission types. License issuance requires certified exam rating, application, purchase/possess permit application, information sheet, and PARA-affiliated club membership certificate.

Section III — Schedule of Fees

Annual license fees: Class A ₱50, B ₱55, C ₱60, D ₱65. Duplicate license ₱50. Exam fee (all classes) ₱50. Station license modification ₱20. Permit to Purchase ₱20/unit, Possess ₱45/unit. Operator Certificate: A ₱55, B ₱45, C/D ₱35. Inspection fee ₱50 (all classes). Late renewal surcharges: 50% (1–180 days), 100% (181–363 days).

Sections IV–V — Repealing Clause, Effectivity

Supersedes inconsistent prior Circulars. Effective immediately upon approval.
